Environment limitation:
  This Linux sandbox does not provide Docker, Windows PowerShell, or pwsh, so it cannot attach
  a real Windows G:/H:/I:/... drive to Docker Desktop. For that reason, a Windows/Docker E2E
  test script was added to the project:

  powershell -ExecutionPolicy Bypass -File .\scripts\test-dynamic-drive-mounts.ps1 `
    -RequiredPath "G:\Ex.1 Darshan SSD 256"

The E2E script verifies the real selected path in Windows, refreshes/recreates the four forensic
containers as necessary, validates the merged Compose model, and verifies the exact path is
readable inside api, worker-disk, worker-mobile, and worker-report. It is drive-letter agnostic.
